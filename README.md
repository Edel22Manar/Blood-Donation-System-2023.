Blood Donation Management System
*Graduation Project - 2023*

A professional web-based platform designed to automate and streamline the blood donation process, connecting donors directly with hospitals to ensure a steady supply of life-saving resources.

---

## 🚀 Project Overview
This project addresses the critical challenge of blood shortages by providing a real-time bridge between healthcare facilities and volunteers. The system manages the entire workflow from donor registration and hospital needs updates to appointment scheduling.

## 🛠 Tech Stack
* *Backend:* Java (JSP/Servlets)
* *Frontend:* HTML5, CSS3, JavaScript
* *Database:* MySQL
* *Design Methodology:* Waterfall Model (Analysis, Design, Implementation, Testing)

## 📋 System Requirements & Quality
The system was engineered to meet strict *Non-Functional Requirements* to ensure a high-quality user experience:

| Requirement | Description |
| :--- | :--- |
| *Usability* | Interface designed for clarity and ease of navigation for all user types. |
| *Reliability* | Consistent performance and data integrity using a robust MySQL backend. |
| *Performance* | Optimized server-side processing for rapid response times. |
| *Security* | Role-based access control (Admin/Donor) with secure authentication. |
| *Extensibility* | Built with a modular structure to support future features like SMS alerts. |
